Este repositorio contiene un formulario dinámico y detallado para la cursada de **Análisis Matemático II**. Está diseñado en **Markdown** para ser visualizado en **Obsidian** y renderizado con **LaTeX** para una máxima precisión matemática.

## Contenidos 
- **Cónicas:** Elipse, Hipérbola, Parábola (Ecuaciones canónicas y desplazadas).
- **Superficies Cuádricas:** (En proceso...)

- Análisis de funciones: **máximos, mı́nimos y puntos silla**
